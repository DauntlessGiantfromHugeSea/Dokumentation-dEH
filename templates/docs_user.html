Anleitung für Helfer

Kompakte Schritt-für-Schritt-Anleitung für alltägliche Aufgaben im Camp.

← Übersicht
1. Erste Anmeldung & 2FA
  1. Im Browser auf die System-URL gehen (Admin sagt dir die Adresse).
  2. Benutzername und Passwort eingeben — wenn du sie noch nicht hast, lass dich von einem Admin anlegen.
  3. Beim ersten Login wirst du durch das 2FA-Setup geführt: Authenticator-App öffnen (z. B. Google Authenticator, Microsoft Authenticator, Aegis, 1Password), QR-Code scannen, den 6-stelligen Code eintippen — fertig.
  4. Beim nächsten Login fragt das System nur noch den 6-stelligen Code ab.
  5. Authenticator-App verloren? Bitte einen Admin um 2FA-Reset; dann läuft das Setup erneut.
2. Dashboard & Berichte-Übersicht
  • Auf Handy oder Tablet kann die Seite als Webapp installiert werden: Browser-Menü → Zum Home-Bildschirm hinzufügen. Danach startet sie wie ein normales Programm.
  • Wenn du für mehrere Veranstaltungen freigeschaltet bist, wechselst du oben rechts in der Topbar die aktive Veranstaltung. Dashboard, Triage, Berichte und Akten zeigen dann genau diese Veranstaltung.
  • Dashboard (Startseite) zeigt Tageszahlen und Schnellzugriff.
  • Berichte ist die zentrale Liste aller Einträge — dezentral (dEH, blau) und zentral (zEH, rot) gemischt, sortiert nach laufender Bericht-Nr.
  • Filter: Name, Stammnummer, Datumsbereich, Typ.
  • Klick auf Öffnen bringt dich auf die Detailseite des Berichts (egal welcher Typ).
  • Neue Berichte kannst du nur anlegen, wenn ein Admin dir für die aktive Veranstaltung die Berechtigung neu anlegen gegeben hat.
3. Dezentralen Bericht (dEH) anlegen
  1. Oben in der Topnav Neuer Bericht → Karte Dezentrale Erste Hilfe wählen.
  2. Pflichtfelder: Name, Geburtsdatum. Live-Lookup zeigt sofort, ob die Person schon im System ist (Folgebehandlung).
  3. Hergang, Verletzung, Maßnahmen, Material — alles ausfüllen, Speichern.
  4. Nach dem Speichern kannst du Kommentare hinzufügen (z. B. „Mutter hat angerufen — alles OK").
  5. PDF herunterladen für die Akte oder den Druck.

Tipp: Der Schnellerfass-Modus links oben (sobald aktiviert) lässt Papierberichte sehr schnell digital nachtragen.

4. Zentrales Notfallprotokoll (zEH)
  1. Topnav → Zentral öffnet das Notfallprotokoll direkt. Cursor steht im Vorname-Feld; sofort lostippen.
  2. Linke Sidebar zeigt automatisch:
    • Bekannte Person mit Stammnummer und Anzahl Vorbehandlungen, oder
    • Mehrere Treffer — Person aus Liste übernehmen, oder
    • Neuer Patient — wird beim Speichern automatisch angelegt.
  3. Im Sidebar-Block Notfall & Medizin siehst du Allergien, Medikamente, Notfallkontakt als Indikatoren (ja/nein/unbekannt).
  4. Mit dem Button Entschlüsseln (Admin-PIN) kann ein Admin seine PIN eingeben, um die Klartext-Daten kurzzeitig anzuzeigen.
  5. Durch die Seiten 1 bis 9 navigieren (Patient → Einsatz → Notfall → Erstbefund → Vitalwerte → Maßnahmen → Verlauf → Übergabe → Abschluss).
  6. Auf Seite 9 unterschreiben beide Einsatzkräfte mit Maus oder Finger im Unterschriften-Pad.
  7. Speichern: das Protokoll wird automatisch beim Tippen gespeichert. Status oben rechts zeigt „Bereit / Speichert / Gespeichert".
5. Anschrift / Krankenkasse / Telefon — Datenschutz
  • Diese Felder dürfen nur Admins eingeben oder einsehen.
  • Auf der Detailseite eines Berichts (/central/<Nr>) gibt es einen Button Daten entschlüsseln (Admin-PIN) — der Admin wählt sich aus dem Dropdown, tippt die PIN, schon erscheint die Anschrift kurzzeitig inline.
  • Jede Freigabe wird protokolliert — wer hat angefordert, wer hat freigegeben, wann. Sichtbar im Akten-Export.
6. Patientenakte ansehen
  • In der Berichteliste oder im SPA auf den Namen klicken — bringt dich auf /patients/<ID>.
  • Du siehst Stammdaten, Vorbehandlungs-Indikatoren und alle bisherigen Berichte (gemischt dezentral/zentral).
  • Klick auf eine Bericht-Zeile öffnet die Detailseite.
7. Tipps für Notfälle
  • Schnell speichern: Im SPA reicht „Speichern" oben oder einfach weiterblättern — das Protokoll wird automatisch zwischengespeichert.
  • Vorbehandlungen sehen: Linke Sidebar im SPA — sobald Name oder Geburtsdatum getippt sind, lädt sie sich live.
  • Mehr als zwei Helfer? Aktuell sind zwei Unterschriften-Pads vorgesehen — Zusatzpersonen ggf. im Verlauf-Feld erwähnen.
  • Falsch gespeichert? Detailseite öffnen → Bearbeiten (eigene Berichte) oder Admin bitten.
8. Häufige Fragen
Ich kann den PDF-Download nicht klicken.
PDF-Generierung im zentralen Notfallprotokoll ist nur für Admins. Frag einen Admin, das PDF zu erzeugen.
Ich sehe die Adresse / Krankenkasse nicht.
Diese Felder sind admin-only. Auf der Detailseite kannst du einen Admin-PIN-Dialog öffnen — der Admin tippt seine PIN ein und du siehst die Daten kurzzeitig.
Mein Authenticator zeigt einen abgelaufenen Code.
TOTP-Codes wechseln alle 30 Sekunden. Den aktuell angezeigten Code neu eingeben — das System akzeptiert ±30 Sekunden Toleranz.
Wie ändere ich mein Passwort?
Oben rechts auf deinen Namen klicken → Passwort ändern.
Wer hat etwas geändert?
Auf der Patientenakte siehst du eine Änderungs-Historie der Stammdaten. Berichte zeigen den Eintragenden im Footer.
