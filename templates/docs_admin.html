Kurzanleitung für Admins

Alles Wichtige für Einstellungen, Rechte, Reports und Betrieb.

Übersicht

Start einrichten

  1. Ersten Admin einloggen.
  2. 2FA einrichten.
  3. Oben rechts Name → Admin-PIN setzen.
  4. PIN wird für Datenfreigaben gebraucht.

Veranstaltungen

  1. Zahnrad → Veranstaltungen.
  2. Name, Präfix, Beginn und Ende eintragen.
  3. Präfix ergibt laufende Nummern wie #C261.
  4. Inaktive Veranstaltungen verschwinden aus der Auswahl.

User & Rechte

  1. Zahnrad → Benutzer anlegen.
  2. Rolle wählen: Voll, Zentral, oder Triage-Kiosk.
  3. Unter Benutzer & Rechte PDF, Akte und Patientendaten setzen.
  4. Unter Veranstaltungen pro User „sehen“ und „neu anlegen“ setzen.

Veranstaltungsreport

  1. Zahnrad → Veranstaltungen.
  2. Bei der Veranstaltung auf Report.
  3. Ort, Veranstalter, Leitung und Helfer ergänzen.
  4. PDF exportieren.

Akten & Datenschutz

  • Patientenakte → Akte exportieren.
  • Notfallkontakt, Allergien, Medikamente und Adressdaten sind geschützt.
  • Admin-PIN gibt Daten kurz frei.
  • Freigaben und Exporte werden protokolliert.

2FA & Passwörter

  • Passwort vergessen: in der Userliste neu setzen.
  • Handy verloren: 2FA zurücksetzen.
  • 2FA ausnahmsweise deaktivieren: Button in der Userliste.
  • Letzter Admin kann nicht entfernt werden.
