Kurzanleitung für Admins

Alles Wichtige für Einstellungen, Rechte, Reports und Betrieb.

Übersicht

Start einrichten

  1. Ersten Admin einloggen.
  2. 2FA einrichten.
  3. Oben rechts Name → Admin-PIN setzen.
  4. PIN wird für Datenfreigaben gebraucht.

Veranstaltungen

  1. Zahnrad → Veranstaltungen.
  2. Name, Präfix, Beginn und Ende eintragen.
  3. Präfix ergibt laufende Nummern wie #C261.
  4. Inaktive Veranstaltungen verschwinden aus der Auswahl.

User & Rechte

  1. Zahnrad → Benutzer anlegen.
  2. Rolle wählen: Voll, Zentral, oder Triage-Kiosk.
  3. Unter Benutzer & Rechte PDF, Akte und Patientendaten setzen.
  4. Unter Veranstaltungen pro User „sehen“ und „neu anlegen“ setzen.

Veranstaltungsreport

  1. Zahnrad → Veranstaltungen.
  2. Bei der Veranstaltung auf Report.
  3. Ort, Veranstalter, Leitung und Helfer ergänzen.
  4. PDF exportieren.

Akten & Datenschutz

  • Patientenakte → Akte exportieren.
  • Notfallkontakt, Allergien, Medikamente und Adressdaten sind geschützt.
  • Admin-PIN gibt Daten kurz frei.
  • Freigaben und Exporte werden protokolliert.

2FA & Passwörter

  • Passwort vergessen: in der Userliste neu setzen.
  • Handy verloren: 2FA zurücksetzen.
  • 2FA ausnahmsweise deaktivieren: Button in der Userliste.
  • Letzter Admin kann nicht entfernt werden.

MANV — Vorbereitung & Alarmierung

Massenanfall-von-Verletzten-Workflow. Komplett vorab vorbereitet, im Ernstfall ein Klick.

1. Sticker-Vorrat vorbereiten
MANV → 📦 Sticker-Vorrat → „+ N neue Sticker erzeugen" (z. B. 100 Stück) → Sticker-PDF drucken (4 A6-Sticker pro A4, im Querformat-Inhalt rotiert) → ausschneiden und auf Blanko- Umhängekarten kleben. Lagern bis zum Bedarf.
2. Blanko-Umhängekarten
MANV → 📦 Sticker-Vorrat → 📄 Blanko-PDF liefert eine doppelseitige A4-Karte. Vorab in großer Stückzahl drucken, Sticker drüberkleben — Karten sind event-übergreifend nutzbar.
3. MANV-Vorfall anlegen (im Voraus oder spontan)
MANV → Vorfälle → + Anlegen. Felder (Name, Karten-Präfix, Situation, Einsatzort, Lagebild) sind alle jederzeit nachpflegbar. Vorfall ist zunächst „geplant" — User sehen ihn noch nicht.
4. 🚨 ALARMIEREN
Auf der Vorfall-Detail-Seite den großen roten Button „🚨 JETZT ALARMIEREN" klicken. Genau ein Vorfall darf gleichzeitig alarmiert sein — neue Alarmierung schließt vorherige automatisch ab. Alle User sehen den Vorfall sofort.
5. Im Einsatz
Helfer scannen die Sticker → Karten landen automatisch im alarmierten Vorfall. Mehrere Sichtungen werden auf der Karte mit Zeit + Sichter protokolliert. Übersichtsprotokoll-PDF (DRK-Format) wird automatisch aus den Karten befüllt.
6. Alarmierung aufheben
Versehentlich alarmiert? Im Vorfall-Detail „Alarmierung aufheben". Daten bleiben, Vorfall ist wieder im Status „geplant" und für User unsichtbar.

Einsatzbefehl & Einsatztagebuch

Strukturierte Einsatzbefehle mit eindeutiger ID, Druck als A4-PDF, optional Einsatztagebuch dazu.

Anlegen
Einsatzbefehle (im Hauptmenü, admin-only) → + Einsatzbefehl anlegen. Kopfdaten genügen am Anfang — Lage / Auftrag / Durchführung / Versorgung / Verbindung / Rückwärtige Führungseinrichtung lassen sich danach jederzeit pflegen.
Eindeutige ID
Format EB-YYYYMMDD-XXXXXXXX (Datum + 8 Hex), wird automatisch vergeben und erscheint im PDF oben rechts.
PDF
Einseitiges A4-Layout, kein Druck-Verschnitt. Button 📄 PDF auf der Detail-Seite.
Einsatztagebuch
Zu jedem Einsatzbefehl kann ein (oder mehrere) Tagebücher angelegt werden. Spaltenformat lfd. Nr. / E/A / Taktische Zeit / Darstellung / Vollzug / Anlage. Einträge laufen automatisch durch, PDF passt sich mehrseitig an die Eintragsanzahl an.
